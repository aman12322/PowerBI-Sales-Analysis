# Power BI Sales Analysis

## Project Overview

This project is a Sales Analysis Dashboard created using Power BI and Excel. It helps analyze sales, profit, orders, customers, products, and employee performance.

## Tools Used

* Power BI
* Excel
* DAX

## Dashboard Pages

### 1. Sales Overview

* Total Sales
* Total Profit
* Total Orders
* Total Quantity
* Average Order Value (AOV)
* Return Rate
* Cancellation Rate
* Category-wise Sales & Profit
* City-wise Sales & Profit
* Top 5 Products
* Employee Performance

### 2. Detailed Analysis

* Top 10 Customers by Sales
* Employee Achievement %
* Return & Cancellation Analysis
* Monthly Sales & Profit Trend
* Interactive Filters and Slicers

## Key Skills Demonstrated

* Data Cleaning and Analysis
* Data Modeling
* DAX Measures
* Power BI Visualizations
* Interactive Dashboards
* Excel Data Analysis
